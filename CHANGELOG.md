# Changelog

What changed in each RigScope release. The app shows this under **Settings › What's new**, and the release workflow
copies the matching section into the GitHub release notes, so every tagged version needs a section here.

Format: `## [version] - yyyy-mm-dd`, optional `### Group` headings, and `- ` bullets.

## [0.1.0] - 2026-10-31

### New
- Competitive check for CS2, VALORANT, Apex Legends, Overwatch 2, Fortnite, Rainbow Six Siege and Marvel Rivals, with impact, evidence level and sources for every finding.
- Myths section that explains which popular tweaks don't help.
- Storage map with folder sizes, largest files, cleanup notes and what changed since the last scan.
- Share report you can paste into Discord or Reddit, with personal details removed by default.
- Measure page with a simple before/after testing method and free tools.
- Settings page: check your PC again, check for updates and see what's new.
- Update check that only contacts GitHub when you press the button. Downloads are saved where you choose and checked against the published SHA-256.
